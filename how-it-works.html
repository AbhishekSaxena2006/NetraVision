Step 01

Image Upload & Validation

The user uploads a retinal fundus photograph via the drag-and-drop interface. The frontend performs immediate validation — checking the file type (JPG/PNG), file size (max 10 MB), and readability before sending it to the server.

Drag & Drop Type Validation Size Check Image Preview
2
Step 02

Image Preprocessing

The uploaded image is preprocessed on the backend: resized to a standardized input dimension (224×224 or 512×512 pixels), normalized pixel values to the range [0, 1], and optionally enhanced using CLAHE (Contrast Limited Adaptive Histogram Equalization) to improve visibility of retinal features.

Resize & Crop Pixel Normalization CLAHE Enhancement Data Augmentation
3
Step 03

CNN Feature Extraction & Analysis

The preprocessed image passes through our Convolutional Neural Network. The CNN uses multiple convolutional layers to extract hierarchical features — from simple edges and textures to complex retinal structures like microaneurysms, hemorrhages, and neovascularization. A pre-trained backbone (e.g., EfficientNet or ResNet) is fine-tuned on the APTOS 2019 dataset.

Convolutional Layers MaxPooling Batch Normalization Transfer Learning Dropout Regularization
4
Step 04

5-Level Classification

The extracted feature vector passes through fully connected dense layers, followed by a Softmax output layer with 5 neurons — one for each DR severity level. The model outputs a probability distribution across all 5 classes, and the class with the highest probability is selected as the prediction.

Dense Layers Softmax Activation 5-Class Output Confidence Scoring
5
Step 05

Result Presentation

The prediction — including the severity level, confidence score, and probability breakdown — is returned via the Flask API as JSON. The frontend renders an interactive results page with severity classification, confidence progress bars, class probability breakdown, and educational recommendations tailored to the detected DR level.

Model Architecture

CNN Architecture Details

Backbone

Pre-trained EfficientNet or ResNet architecture, fine-tuned on medical retinal images for domain-specific feature extraction.

Training Data

APTOS 2019 Blindness Detection Dataset from Kaggle — thousands of labeled retinal fundus images across all 5 severity levels.

Training Strategy

Transfer learning with frozen backbone layers initially, then end-to-end fine-tuning. Data augmentation used to handle class imbalance.

Evaluation Metrics

Accuracy, Quadratic Weighted Kappa (QWK), Precision, Recall, and F1-Score across all 5 classes on a held-out test set.

Tech Stack

Python, TensorFlow, Keras, Flask for the API. NumPy, OpenCV for preprocessing. Frontend: HTML, CSS, Vanilla JavaScript.

API Format

RESTful Flask endpoint /api/predict accepts multipart form data and returns JSON with level, label, confidence, and probabilities.

FAQ

Common Questions

Is NetraVision a certified medical device?
No. NetraVision is a college research project and is not certified by any medical regulatory authority. It is designed for educational and research purposes only. Always consult a qualified ophthalmologist for medical advice.
Are my uploaded images stored or shared?
No. Images are only used for the duration of the analysis and are not stored on any server. Your data remains private and is never shared with third parties.
What type of retinal images does NetraVision accept?
NetraVision accepts retinal fundus photographs in JPG or PNG format, up to 10 MB. For best results, use a clear, well-lit fundus photograph with the retina centered in the frame.
How accurate is the AI model?
Our CNN model achieves competitive accuracy on the APTOS 2019 test set, measured using Quadratic Weighted Kappa (QWK) and overall accuracy. The exact metrics are documented in our project report. Remember: accuracy on a test dataset does not guarantee real-world clinical performance.
Can I use this for a real patient?
Absolutely not. NetraVision is for educational use only and must never be used to make clinical decisions for real patients. It cannot replace the judgment of a trained ophthalmologist.
