Core Capabilities

What NetraVision Offers

AI-Powered Deep Learning

Our Convolutional Neural Network is trained on thousands of labeled retinal images using transfer learning from proven architectures like EfficientNet — achieving medically significant classification accuracy.

Five Severity Level Classification

Classifies retinal images into 5 internationally recognized DR levels: No DR, Mild, Moderate, Severe, and Proliferative — giving users precise, actionable information about disease progression.

Drag & Drop Image Upload

Intuitive drag-and-drop interface with instant image preview, automatic file type validation (JPG/PNG), size checking, and the ability to remove and replace images before analysis.

Real-Time Results

Receive comprehensive prediction results with confidence scores, probability breakdown across all 5 classes, severity classification badge, and animated visual indicators in under 3 seconds.

Fully Responsive Design

Optimized for all screen sizes — desktop, tablet, and mobile. Adaptive navigation with a hamburger menu, fluid grid layouts, and touch-friendly interfaces for seamless mobile use.

Privacy-First Architecture

Images are processed only for analysis and are never permanently stored or shared. No account required, no data collection, no third-party tracking — your medical images remain 100% private.

Downloadable Reports

Generate and download a complete analysis report as a text file — including severity level, confidence score, probability breakdown, and educational recommendations for each severity class.

Educational Recommendations

Each result page includes tailored educational guidance specific to the detected severity level — from routine monitoring for No DR to urgent referral guidance for Proliferative DR.

Classification Levels

The 5 Severity Levels

NetraVision classifies diabetic retinopathy using the internationally accepted 5-level grading scale.

0
No DR
Normal retina. No signs of diabetic retinopathy detected.
1
Mild DR
Microaneurysms only. Earliest stage of retinopathy.
2
Moderate DR
More than microaneurysms. Hemorrhages and exudates present.
3
Severe DR
Severe hemorrhages and significant retinal ischemia.
4
Proliferative DR
Neovascularization. Advanced stage with high risk of blindness.
